# 📖 Interactive Storytelling Engine

A Llama-based system that creates branching narratives based on user input.

**Author:** Pranay M

## 🌟 Features

| Module | Description |
|--------|-------------|
| **Story Generator** | Generate story segments |
| **Character Manager** | Create and develop characters |
| **World Builder** | Build immersive worlds |
| **Choice Engine** | Generate meaningful choices |
| **Narrative Tracker** | Track story elements |
| **Dialogue Creator** | Create character dialogue |
| **Tension Controller** | Control dramatic tension |
| **Ending Weaver** | Create satisfying endings |
| **Save Manager** | Save/load progress |
| **Theme Selector** | Choose story themes |

## 🚀 Quick Start

```bash
ollama pull llama3.2 && ollama serve
pip install -r requirements.txt
python main.py
```
